# Model Prism update · September 13, 2026

This release refreshes the model catalog and fixes the review flow from input through persistence and export.

## Models

The default council has five complementary models: GPT-5.6 Sol, Gemini 3.8 Flash, DeepSeek V4.1 Flash, MiniMax M3, and GLM 5.3 Flash. A separate advanced council adds GPT-6 Astra, Grok 4.6, Qwen3.8 Max, and Kimi K3. Synthesis offers Claude Sonnet 5, Opus 5, and Fable 5.1.

All roles share reviewed IDs and a metadata snapshot checked against the [OpenRouter catalog](https://openrouter.ai/api/v1/models). Context windows, output limits, reasoning options, and supported request parameters come from that catalog. Image-generation models are excluded. GPT-6 Astra is restricted to text review in the chat-completions implementation; agentic reviewers use models compatible with chat tool calls.

The daily freshness workflow is enabled. CI and run preflight also check availability. Changes in prices or capabilities are reported separately from successor suggestions, and product tiers are kept distinct. An available model is not automatically considered a better reviewer.

## Run reliability and safety

- Input, instructions, context, and reasoning are frozen per run. Edits start a new run.
- Stop aborts requests, queued reviewers, and retry waits. It cannot start synthesis afterward.
- Complete answers persist; errors, truncated answers, and cancellations remain resumable and are excluded from synthesis.
- IndexedDB and private cloud checkpoints retain response states and spending records. Matching CLI reviews also resume from an adjacent state file.
- New cloud checkpoints use access derived from the user's OpenRouter key. Connecting the same key on another device restores access. Legacy records retain their existing access rules.
- Markdown is rendered without executable raw HTML, unsafe URLs, or remote model-supplied images.
- Usage prefers provider-reported costs, accounts for retries and every review phase, deduplicates saves, and reserves concurrent request costs before dispatch. Uncertain interrupted charges remain explicitly reserved.
- Findings carry source references and exact quotations. Evidence coverage measures traceability; it is not a correctness or confidence score. Legacy reviews remain unscored.

## Interface

Phone layouts use Setup and Results tabs, a persistent Run/Stop control, readable forms, searchable model selection, and accessible selection states. History, Settings, Models, and Hooks use the same colors. Saved exports include the full master document. Save failures stay visible with a retry action.

## Verification

The production build, TypeScript, lint, unit regression suite, and six browser tests pass. Browser coverage includes desktop and 390px mobile layouts, unsafe Markdown, input edits, cancellation, save failures, and restore/resume. Database checks verify private access, accumulated costs, duplicate saves, stale revisions, and input identity.

The dependency audit reports zero vulnerabilities after upgrading Next.js to 16.3.5 and updating the dependency tree. Both lockfiles are refreshed; Vercel uses `npm ci`.

The live evaluation was blocked by insufficient OpenRouter credits. DeepSeek also returned an account data-policy restriction. No credits were spent, and no live quality ranking is claimed. The included opt-in evaluation harness can be rerun after the account is ready.

Browser execution pauses when the tab closes; reopening restores the checkpoint. Budgets cover one active execution. Simultaneously resuming the same run on multiple devices is not supported.
